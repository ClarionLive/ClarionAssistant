## Component-specific notices

### Microsoft Edge WebView2

The WebView2 SDK and loader are redistributed under Microsoft's own distribution terms, which
accompany the WebView2 SDK package. They are not an OSI open-source licence and are not reproduced
here. See the [WebView2 SDK licence terms](https://developer.microsoft.com/microsoft-edge/webview2/).

The WebView2 **Runtime** itself is not redistributed by this installer; it is installed separately by
Microsoft or already present on the machine.

### SQLite / System.Data.SQLite

SQLite and System.Data.SQLite are released into the **public domain**. From the upstream notice:

> The author disclaims copyright to this source code. In place of a legal notice, here is a blessing:
>
> May you do good and not evil.
> May you find forgiveness for yourself and forgive others.
> May you share freely, never taking more than you give.

`System.Data.SQLite.dll` carries the copyright string "Copyright © 2004-2008 Hipp, Wyrick & Company,
Inc." in its version resource; the code is nonetheless released to the public domain by its authors.

### Everything SDK (voidtools)

`Everything32.dll` is the IPC client DLL from the voidtools Everything SDK. Everything is distributed
under a permissive licence equivalent to the MIT License, requiring that copyright notices be retained
in copies. The authoritative text is published at <https://www.voidtools.com/License.txt>.

Everything itself is **not** redistributed — only the SDK client DLL. Clarion Assistant's
Everything-backed search features require Everything to be installed separately by the user.

### Node.js

Node.js v24.13.0 is redistributed as `node.exe` so that end users need not install Node separately.

Node.js is licensed under the MIT License, but its distribution aggregates a large number of bundled
dependencies under their own licences — including V8, OpenSSL, ICU, zlib, llhttp and others. That
combined notice is far too large to reproduce here and is maintained upstream.

The authoritative licence text for the exact version redistributed is:
<https://github.com/nodejs/node/blob/v24.13.0/LICENSE>

> **Known gap.** This is a reference, not a copy. The Windows Node.js installer does not place a
> `LICENSE` file on disk, so there was no local copy to vendor. Shipping recipients an actual copy of
> Node's licence bundle is tracked as an open item on ticket `c93e3f55` and is not yet done.
